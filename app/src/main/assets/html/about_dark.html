About

The SpinSpinner app is designed to generate random spins that follow the ISU guidelines for spins in achieving levels of difficulty. Different options can be set to modify the quality of the spins that are generated. SpinSpinner does not generate exact spins (i.e. Cannon, Haircutter, Catchfoot) instead it only generates a random set of "qualities" that are required to achieve levels. It is then up to the skater how to achieve those qualities. Be creative!
